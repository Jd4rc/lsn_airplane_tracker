# Airplane Tracker

## О проекте

Airplane Tracker — учебный проект на Python для получения информации о воздушных судах с использованием внешних API.

На текущем этапе проект умеет:

- искать географические объекты через Nominatim;
- получать границы найденной области;
- запрашивать список воздушных судов в выбранном регионе через OpenSky Network;
- преобразовывать ответы OpenSky в объекты `Aircraft`.

## Используемые API

* **Nominatim OpenStreetMap** — поиск географических объектов и получение их координат.
* **OpenSky Network** — получение информации о воздушных судах в указанной области.

## Возможности

На данный момент проект позволяет:

* получать координаты географических объектов через Nominatim;
* получать границы выбранной области;
* выполнять запросы к OpenSky Network;
* получать информацию о воздушных судах в заданной области;
* работать с API через единый базовый клиент;
* преобразовывать данные OpenSky в объекты `Aircraft`;
* искать воздушные суда по названию города через CLI;
* форматированно выводить сведения о найденных самолётах;
* обрабатывать ситуацию, когда самолёты в выбранной области не найдены;
* получать топ N самолётов по высоте полёта;
* исключать из рейтинга самолёты без данных о высоте;
* фильтровать воздушные суда по стране регистрации;
* выполнять поиск по стране без учёта регистра;
* проверять компоненты проекта с помощью модульных тестов.

## Использование CLI

### Обычный поиск

Для поиска всех самолётов поблизости от указанного города:

```bash
python -m src.cli search Moscow
```

После выполнения команды приложение:

1. получает границы указанной области через Nominatim;
2. запрашивает самолёты через OpenSky Network;
3. преобразует ответ API в объекты `Aircraft`;
4. выводит информацию в консоль;
5. сохраняет результаты в JSON-файл в директории `data`.

### Фильтрация по стране регистрации

Опция `--country` позволяет вывести самолёты, зарегистрированные в указанной стране:

```bash
python -m src.cli search Berlin --country Germany
```

Сравнение названий стран выполняется без учёта регистра, поэтому `Germany`, `germany` и `GERMANY` обрабатываются одинаково.

Название страны из нескольких слов нужно заключить в кавычки:

```bash
python -m src.cli search London --country "United Kingdom"
```

### Топ самолётов по высоте

Опция `--top-altitude` принимает количество самолётов, которое нужно вывести:

```bash
python -m src.cli search Moscow --top-altitude 5
```

Самолёты без данных о высоте исключаются, а остальные сортируются по высоте в порядке убывания.

Значение `--top-altitude` должно быть больше нуля.

> Опции `--country` и `--top-altitude` нельзя использовать одновременно.

### Параметры команды `search`

| Параметр | Обязательный | Описание |
|---|---:|---|
| `city` | Да | Город или географическая область поиска |
| `--country COUNTRY` | Нет | Фильтрация по стране регистрации |
| `--top-altitude N` | Нет | Вывод `N` наиболее высоко летящих самолётов |

Чтобы посмотреть справку:

```bash
python -m src.cli search --help
```
## Тестирование

Запуск всех тестов:

```bash
pytest
```

Запуск с отображением покрытия:

```bash
pytest --cov=src --cov-report=term-missing
```

Для метода `get_top_aircraft_by_altitude()` проверяются:

* сортировка самолётов по высоте;
* ограничение количества результатов;
* исключение самолётов без высоты;
* исключение самолётов на земле;
* обработка некорректного значения `limit`.
