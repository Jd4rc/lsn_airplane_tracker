# Airplane Tracker

## О проекте

Airplane Tracker — учебный проект на Python для получения информации о воздушных судах через внешние API, обработки полученных данных и сохранения их в PostgreSQL.

Проект получает географические данные через Nominatim, информацию о самолётах через OpenSky Network, преобразует ответы API в объекты `Aircraft` и позволяет сохранять и анализировать полученные данные в базе данных.

## Используемые технологии

* Python
* PostgreSQL
* psycopg2
* requests
* python-dotenv
* pytest
* pytest-cov

## Используемые API

* **Nominatim OpenStreetMap** — поиск географических объектов и получение их координат.
* **OpenSky Network** — получение информации о воздушных судах в указанной области.

## Возможности

На данный момент проект позволяет:

* получать координаты географических объектов через Nominatim;
* получать границы выбранной области;
* выполнять запросы к OpenSky Network;
* получать информацию о воздушных судах в заданной области;
* преобразовывать данные OpenSky в объекты `Aircraft`;
* искать воздушные суда по названию города через CLI;
* фильтровать самолёты по стране регистрации;
* получать топ N самолётов по высоте;
* сохранять результаты в JSON;
* создавать таблицы PostgreSQL для хранения стран и самолётов;
* загружать данные о странах и воздушных судах в PostgreSQL;
* обновлять данные о существующих странах;
* заменять устаревший список самолётов страны актуальными данными;
* получать данные из PostgreSQL через класс `DBManager`;
* выполнять агрегирующие и фильтрующие запросы к данным о самолётах;
* загружать актуальные данные в PostgreSQL через точку входа `loader.py`;
* работать с сохранёнными данными через точку входа `main.py`;
* выполнять автоматические тесты проекта.

## Работа с базой данных

Для хранения данных используется PostgreSQL.

Основные таблицы:

### `countries`

Содержит информацию о странах и их географических границах:

* `id`;
* `name`;
* `south_lat`;
* `north_lat`;
* `west_lon`;
* `east_lon`.

### `aeroplanes`

Содержит информацию о воздушных судах:

* `id`;
* `icao24`;
* `callsign`;
* `origin_country`;
* `longitude`;
* `latitude`;
* `baro_altitude`;
* `velocity`;
* `true_track`;
* `vertical_rate`;
* `on_ground`;
* `country_id`.

Самолёты связаны со странами через внешний ключ `country_id`.

## Модули базы данных

### `connection.py`

Отвечает за создание подключения к PostgreSQL с помощью `psycopg2`.

Параметры подключения загружаются из переменных окружения.

### `schema.py`

Содержит SQL-схему и отвечает за создание необходимых таблиц базы данных.

### `data_loader.py`

Отвечает за загрузку данных в PostgreSQL.

Основные операции:

* добавление страны;
* обновление существующей страны при конфликте по названию;
* загрузка списка самолётов;
* удаление устаревших данных о самолётах перед загрузкой актуального списка.

### `db_manager.py`

Содержит класс `DBManager` для работы с сохранёнными данными.

Класс предоставляет следующие методы:

* `get_countries_and_aeroplanes_count()` — получает список стран и количество самолётов в их воздушном пространстве;
* `get_all_aeroplanes()` — получает список всех самолётов;
* `get_avg_velocity()` — получает среднюю скорость самолётов;
* `get_aeroplanes_with_higher_velocity()` — получает самолёты со скоростью выше средней;
* `get_aeroplanes_with_keyword()` — ищет самолёты по символам, содержащимся в позывном.

## Точки входа

### `loader.py`

Точка входа для загрузки актуальных данных в PostgreSQL.

Скрипт:

1. получает географические границы выбранных стран через Nominatim;
2. получает список самолётов в их воздушном пространстве через OpenSky Network;
3. сохраняет или обновляет данные о странах;
4. заменяет старый список самолётов каждой страны актуальными данными.

Запуск:

```bash
poetry run python loader.py
```

Перед запуском необходимо настроить подключение к PostgreSQL и создать таблицы.

### `main.py`

Точка входа для работы с уже сохранёнными данными через класс `DBManager`.

Скрипт позволяет проверить основные операции чтения и анализа данных:

* количество самолётов по странам;
* получение списка всех самолётов;
* вычисление средней скорости;
* получение самолётов со скоростью выше средней;
* поиск самолётов по части позывного.

Запуск:

```bash
poetry run python main.py
```

## Настройка базы данных

Для работы проекта необходимо создать PostgreSQL-базу данных и настроить переменные окружения.

Пример `.env`:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=airplane_tracker
DB_TEST_NAME=airplane_tracker_test
DB_USER=postgres
DB_PASSWORD=your_password
```

Для создания таблиц можно запустить модуль схемы:

```bash
poetry run python -m src.database.schema
```

После создания таблиц можно загрузить актуальные данные о странах и самолётах:

```bash
poetry run python loader.py
```

Для работы с сохранёнными данными через `DBManager`:

```bash
poetry run python main.py
```

## Использование CLI

### Обычный поиск

Для поиска всех самолётов поблизости от указанного города:

```bash
python -m src.cli search Moscow
```

После выполнения команды приложение:

1. получает границы указанной области через Nominatim;
2. запрашивает самолёты через OpenSky Network;
3. преобразует ответ API в объекты `Aircraft`;
4. выводит информацию в консоль;
5. сохраняет результаты в JSON-файл в директории `data`.

### Фильтрация по стране регистрации

```bash
python -m src.cli search Berlin --country Germany
```

Сравнение названий стран выполняется без учёта регистра.

Название страны из нескольких слов необходимо заключить в кавычки:

```bash
python -m src.cli search London --country "United Kingdom"
```

### Топ самолётов по высоте

```bash
python -m src.cli search Moscow --top-altitude 5
```

Самолёты без данных о высоте исключаются, а остальные сортируются по высоте в порядке убывания.

Значение `--top-altitude` должно быть больше нуля.

> Опции `--country` и `--top-altitude` нельзя использовать одновременно.

### Параметры команды `search`

| Параметр            | Обязательный | Описание                                    |
| ------------------- | -----------: | ------------------------------------------- |
| `city`              |           Да | Город или географическая область поиска     |
| `--country COUNTRY` |          Нет | Фильтрация по стране регистрации            |
| `--top-altitude N`  |          Нет | Вывод `N` наиболее высоко летящих самолётов |

Для просмотра справки:

```bash
python -m src.cli search --help
```

## Тестирование

Для тестирования используется `pytest`.

Запуск всех тестов:

```bash
poetry run pytest
```

Запуск тестов с отображением покрытия:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Тесты используют отдельную PostgreSQL-базу данных, чтобы не изменять данные основной базы.

Проверяются в том числе:

* добавление и обновление стран;
* загрузка списка самолётов;
* замена старых данных о самолётах актуальными;
* получение списка всех самолётов;
* подсчёт количества самолётов по странам;
* вычисление средней скорости;
* поиск самолётов со скоростью выше средней;
* поиск самолётов по части позывного.
