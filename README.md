# Airplane Tracker

## О проекте

Airplane Tracker — учебный проект на Python для получения информации о воздушных судах с использованием внешних API.

На текущем этапе проект умеет:

- искать географические объекты через Nominatim;
- получать границы найденной области;
- запрашивать список воздушных судов в выбранном регионе через OpenSky Network;
- преобразовывать ответы OpenSky в объекты `Aircraft`.

## Используемые API

* **Nominatim OpenStreetMap** — поиск географических объектов и получение их координат.
* **OpenSky Network** — получение информации о воздушных судах в указанной области.

## Возможности

На данный момент проект позволяет:

* получать координаты географических объектов через Nominatim;
* получать границы выбранной области;
* выполнять запросы к OpenSky Network;
* получать информацию о воздушных судах в заданной области;
* работать с API через единый базовый клиент;
* преобразовывать данные OpenSky в объекты `Aircraft`;
* искать воздушные суда по названию города через CLI;
* форматированно выводить сведения о найденных самолётах;
* обрабатывать ситуацию, когда самолёты в выбранной области не найдены;
* проверять компоненты проекта с помощью модульных тестов.

## CLI

Для поиска воздушных судов по названию города используется команда `search`.

```bash
python -m src.cli search Minsk
```
CLI выполняет следующие действия:

принимает название города;
получает границы области через Nominatim;
запрашивает воздушные суда в этой области через OpenSky;
преобразует полученные данные в объекты Aircraft;
выводит сведения о найденных самолётах в консоль.

Для каждого воздушного судна выводятся:

ICAO24;
позывной;
высота;
скорость;
направление движения;
статус нахождения на земле.

Если значение одного из полей отсутствует, вместо него выводится unknown.

Если воздушные суда не найдены, программа выводит соответствующее сообщение.

Справку по доступным командам можно получить так:
```
python -m src.cli --help

```

### API-клиенты

Отвечают только за взаимодействие с внешними сервисами.

- `NominatimAPIClient`
- `OpenSkyAPIClient`

### Модели

Содержат доменные объекты приложения.

- `Aircraft`

### Сервисы

Содержат бизнес-логику приложения.

`FlightService` объединяет работу API-клиентов, получает границы выбранной области, запрашивает самолёты через OpenSky и преобразует полученные данные в объекты `Aircraft`.
