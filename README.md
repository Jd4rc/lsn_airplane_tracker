# Airplane Tracker

## О проекте

Airplane Tracker — учебный проект на Python для получения информации о воздушных судах с использованием внешних API.

На текущем этапе реализован клиент для работы с API Nominatim, который используется для поиска географических объектов и получения их координат.

## Используемые API

- Nominatim OpenStreetMap — поиск географических объектов и получение координат.
